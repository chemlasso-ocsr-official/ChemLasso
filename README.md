# ChemLasso
ChemLasso is a Chrome/Edge extension that turns chemical structure images into editable molecules. Lasso any drawing in a paper, patent or PDF to get SMILES, a 2D editor and a 3D view. Recognition runs fully on-device (WebGPU/WASM): no server, no API key, offline by default. Optional PubChem/Wikidata lookup for CAS numbers and supplier links.
